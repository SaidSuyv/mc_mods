# Minecraft MODS 1.21.1

This is my minecraft modpack for Minecraft v1.21.1.

# How to install

1. Make sure to have installed the Fabric mod loader v1.21.1
2. Clone the repository inside the .minecraft folder with the name of "mods"
  `git clone https://github.com/SaidSuyv/mc_mods mods`
3. Point out the version of desired (this case 1.21.1)
4. Enjoy the game!
